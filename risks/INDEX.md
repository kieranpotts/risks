# Workshop index

The catalog of every threat modeling workshop report merged into `latest/main`.

Workshops are listed newest first. New workshop reports are appended on merge
to `latest/main`. The index is an append-only stack. Reports are treated as
immutable once they are added to the index — never subsequently edited or
deleted.

The date is when the workshop was held. The "Risks raised" column counts how
many rows the workshop added to [risk register](./REGISTER.md). Each risk's
current status is subsequently tracked via the register.
