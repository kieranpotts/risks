# Draft report

Scaffolds a blank report to capture the findings from a new threat
modeling workshop.

Cuts a `report/<slug>` branch from `main`, prepares a fresh report from the
template, and opens a pull request in a draft state.

## How to invoke

> Draft report

> Draft a new report

> Prepare a threat modeling workshop report

> Threat model the payment flow.

## Recommended models

A fast, cheap model is sufficient for this skill. It only scaffolds the
report; the workshop itself comes later.
