# Update register

Updates the living risk register in place — mitigations shipped, reviews
due, or risks retired — without a workshop.

## How to invoke

> Update register

> The MFA mitigation for TA1 is shipped.

> Mark risk TA1 as mitigated

> Review the register

> Retire this risk

## Recommended models

A mid-tier model is sufficient for this skill. Editing the rows is mechanical,
but judging whether a mitigation has genuinely shipped requires a bit more
effort.
